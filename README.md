# Wallpaper Cycler

A small menu bar app for macOS that cycles your desktop wallpaper.

Free forever, and completely open source. No account signup or telemetry.

## What you need

- macOS 13 or later
- Xcode command line tools:
```bash
    xcode-select --install
```

## Run it

```bash
    swift run
```

The app will appear in the top menu bar, not in the dock.
